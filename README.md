===

> Content-addressed, algebraically-composable runtime for Stratified Homoiconic systems

**Compose applications from declared semantic models.**

This is an experimental AI-first codebase built with AI and for AI with the goal of making it easy to follow and understand by humans.
Nothing other than this readme has been touched by human hands.

It is an early research preview released for feedback. The code has not been thoroughly reviewed yet as it still changes too much.

See [PAPER.md](./PAPER.md) and [OVERVIEW.md](./OVERVIEW.md) for an introduction.

You are encouraged to use AI to explore the project and have AI explain it to you.

Look at [examples/todomvc/](./examples/todomvc/) which is a simple complete example of the famous application. The other examples are only partially working.

Ask AI to make changes and see how it goes.

We look forward to seeing what you build.


Usage
---

```
bun install

bun bin/rak serve --example todomvc
```


Contibute
---

We welcome contributions of all kinds.

**A caution on code contributions:** We use a `codex` swarm of coding agents fed by `claude` writing work packs to implement this codebase.
This is an AI-first codebase and unless you use AI to code you will be disappointed when we re-implement your idea on top of your branch to make it fit.
It is likely that any branch you push will diverge from `main` quickly. We don't care and that will not stop your idea from being absorbed.

You will need to use AI to keep refactoring changes in your clone as we push to `main` in case you want to keep up with us.

The best way to contribute is to play around, try and implement new kernel features, submit working code with test coverage and all tests passing (in the PR branch), and wait for us to absorb it and push a new release.
